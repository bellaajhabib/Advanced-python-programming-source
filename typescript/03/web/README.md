# OOP Dogs: TypeScript Web App

This Vite app runs in a browser and demonstrates the `Dog` class from `typescript/03/oop.ts`. Dog objects live in the TypeScript app, which lets you add dogs, call `bark()`, and change one object's age with `birthday()`.

## Run

From PowerShell:

```powershell
cd typescript\03\web
npm install
npm run dev
```

Open the localhost URL printed by Vite (usually <http://localhost:5173>). Press `Ctrl+C` to stop. Node.js 24 is available in the project Dev Container.

This is a front-end learning example: data is held in browser memory and resets on reload. It is not a production service.
