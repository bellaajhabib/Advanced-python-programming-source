# Java resume lessons

The six files follow the same learning order as the Python lessons: basics,
strings, functional streams, iterators, wrappers, and the complete matcher.

Compile an individual lesson from this directory:

```powershell
javac 03_Functional.java
java Functional
```

Compile the complete matcher with `javac ResumeMatcher.java`, then run
`java ResumeMatcher`. Java uses `Iterator` for generator-style processing and
wrapper functions for decorator-style behavior.
